# Experiments (not core product)

These prototypes explore **side-income workflows**. They are **not** the primary Noahubai / AI Hub product and are **not** included in Free/Pro/Team pricing.

| File | Purpose | Status |
|------|---------|--------|
| [`moneymaer demo.html`](../../moneymaer%20demo.html) | Job board aggregator + demo earnings UI | Experiment |
| [`AGENT WORK.html`](../../AGENT%20WORK.html) | Freelance lead finder + pitch generator | Experiment |

## Why they are separate

The monetization strategy centers on **AI Hub** as a local AI workspace for Cursor power users. Job and freelance demos:

- Use external platforms for real payouts (Upwork, Fiverr, etc.)
- Do not integrate with Noahubai billing or entitlements
- Would confuse the product story if marketed as the main app

## If you want to productize an experiment

1. Fork or move it to its own repo / product line
2. Define a separate audience and pricing page
3. Do not merge experiment billing into the AI Hub entitlement system unless deliberately scoped

For the official product definition, see [`../PRODUCT.md`](../PRODUCT.md).
