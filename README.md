# Noahubai

Unified AI with memory, issue tracking, and auto-fixing.

**GitHub library:** https://github.com/ezsoftwarez/Noahubai

## Quick start (Windows)

### Desktop shortcut — original app + Bridge auto-start

1. Clone this repo (or copy to `DEMOCORE DAW` folder layout)
2. Run **`CREATE-NOAHUBAI-DESKTOP-SHORTCUT.bat`** once
3. Double-click **Noahubai OG** on your Desktop

Or run **`RUN-NOAHUBAI-OG.bat`** directly — starts:

- AI Hub Bridge → http://127.0.0.1:8765
- Noahubai OG (Windows 7 shell) → http://127.0.0.1:8000

### Manual

```bat
python main.py
```

API docs: http://localhost:8000/docs
