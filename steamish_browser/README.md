# Steamish Browser — restart from your code

Beépítve:
- TabVault (OneTab-szerű): Ctrl+Shift+O + about:tabvault
- KoboldBlock (adblock): Settingsben kapcsolható + rules szerkeszthető
- Bookmarks page: Ctrl+Shift+B + about:bookmarks
- VirusTotal: csak HTTP (nem secured) oldalra fut (ha be van kapcsolva + van API key)

## Run (Windows)
1) python -m venv .venv
2) .venv\Scripts\activate
3) pip install -r requirements.txt
4) python main.py
